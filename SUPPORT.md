# Farm Sim Manager Support Workflow

This repository is the public support and feedback tracker for Farm Sim Manager. The application source and internal development repository remain private.

## Where to report things

### Bug reports

Use the **Bug report** issue form for reproducible application problems, crashes, incorrect behaviour, installation problems, FS25 detection problems, mod/save/profile issues, Compare problems and launcher failures.

### Feature requests

Use the **Feature request** issue form for workflow improvements or new capabilities.

### General usage help

Check the current Farm Sim Manager user guide and Quick Start on **https://simgamerjen.com** before opening an issue. If a question reveals unclear behaviour or poor documentation, it may be converted into a documentation/usability issue.

### Sensitive diagnostics

Do not post unreviewed support bundles or private diagnostic material publicly. If maintainers request additional diagnostics, use the private contact route on **https://simgamerjen.com** and reference the public GitHub issue number.

## What happens after a report is opened

A report will normally move through these stages:

1. **Triage** — confirm version, affected area, reproduction information and whether the report is a duplicate.
2. **Needs information** — ask for missing reproduction details or privately supplied diagnostics when required.
3. **Confirmed** — the behaviour has been reproduced or enough evidence exists to treat it as a defect.
4. **Planned / in development** — a fix or change has been accepted for a future build.
5. **Fixed / released** — the relevant fix has shipped in a Community Preview build.
6. **Closed** — resolved, duplicate, not reproducible, expected behaviour or not planned.

The public issue does not expose private source-code activity. Where useful, maintainers may reference a release/version in which the fix is expected or delivered.

## Information that helps most

The fastest reports to diagnose usually include:

- exact Farm Sim Manager version;
- installer vs portable package;
- Windows version;
- FS25 distribution when launcher/detection is involved;
- shortest reliable reproduction steps;
- expected and actual behaviour;
- exact safe-to-share error text;
- whether the problem is consistent or intermittent;
- a note that a reviewed support bundle is available privately if needed.

## Community Preview expectations

Farm Sim Manager is pre-release software. Not every suggestion will be implemented and not every defect can be fixed immediately. Reports that risk save data, mod-folder configuration, profile activation or launch safety take priority over cosmetic defects.
