# Security and Privacy Reports

The Farm Sim Manager support repository is public. Do not publish sensitive security or privacy information here.

## Do not post publicly

Do not include any of the following in a GitHub issue:

- passwords or account credentials;
- API keys, tokens or private keys;
- unredacted personal information;
- unreviewed Farm Sim Manager support bundles;
- full logs containing information you consider private;
- private filesystem paths or filenames you do not want made public;
- information that would unnecessarily expose a security vulnerability before it can be assessed.

## How to report privately

Use the contact route on **https://simgamerjen.com** for security/privacy-sensitive reports or diagnostic material that should not be public.

If there is already a public bug report for the non-sensitive symptoms, include its GitHub issue number in the private message so the two reports can be correlated without publishing the sensitive material.

Farm Sim Manager Community Preview users should always review support bundles and logs before sharing them.
