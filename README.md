# Farm Sim Manager Support

Public support and feedback tracker for **Farm Sim Manager by SimGamerJen**.

Farm Sim Manager is distributed through **https://simgamerjen.com**. The application source repository is private; this repository exists so Community Preview users can report bugs, request features and follow known issues without requiring access to the source code.

## Before opening an issue

Please make sure you are using the latest Farm Sim Manager build available from simgamerjen.com and check existing open and closed issues first.

For normal usage guidance, use the Farm Sim Manager user guide and Quick Start published alongside the application on simgamerjen.com.

## Report a bug

Use the **Bug report** issue form. A useful report should include:

- Farm Sim Manager version;
- installer or portable build;
- Windows version;
- Farming Simulator 25 platform/distribution where relevant;
- clear steps to reproduce the problem;
- expected behaviour;
- actual behaviour;
- whether the problem happens every time;
- any safe-to-share screenshots or exact error text.

### Support bundles and logs

Farm Sim Manager can export a support bundle from the **About** window.

**Do not upload a support bundle, full log, or other diagnostic archive to a public GitHub issue unless you have reviewed it first.** Diagnostic files can contain local filesystem paths, usernames, custom folder names or other information you may not want to publish.

If a support bundle is needed, state in the issue that you can provide one privately when requested.

## Feature requests

Use the **Feature request** issue form. Please explain the problem or workflow you want to improve rather than only describing a button or implementation.

## What belongs here

This repository is for:

- reproducible Farm Sim Manager bugs;
- installation and launch problems;
- mod/save/profile management issues;
- Compare and diagnostics issues;
- usability problems;
- feature requests and workflow improvements;
- confirmed Community Preview known issues.

It is not a general Farming Simulator 25 support forum and it does not contain the Farm Sim Manager source code.

## Security or privacy-sensitive reports

Do **not** post passwords, access tokens, private keys, personal data, unredacted diagnostic archives, or other sensitive information in a public issue. For a report that may involve sensitive information, use the contact route on **https://simgamerjen.com** instead of publishing the details here.

## Current status

Farm Sim Manager is currently in Community Preview. Pre-release builds may contain bugs and incomplete features. Back up important Farming Simulator 25 saves, settings and custom mod-folder configuration before testing.

The current Windows binaries may also trigger Microsoft Defender SmartScreen because they are not yet Authenticode-signed.
